# AIXX (Wanan Exchange 万安算交所)

**The world's first verification-first compute exchange.**
Every GPU and full system listed has passed on-site physical inspection with a traceable, numbered report; every buyer has passed real-name identity and funds verification. Reports match identities, every number is checkable, every trade is traceable.
